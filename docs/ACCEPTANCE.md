# 项目验收清单

本文件用于记录前端实训作业的功能验收范围。

## 自动化检查

- [x] ESLint 代码规范检查
- [x] 日期、连续打卡、本地存储单元测试
- [x] Vue 组件交互单元测试
- [x] Vite 生产构建

运行 `npm run check` 可重新执行以上检查。

## 功能验收

- [x] 合法时长可保存，非法、负数和空值会提示
- [x] 计时器支持开始、暂停、重置和专注/休息切换
- [x] 完成专注后自动累计当日专注时长并切换休息模式
- [x] 任务支持增删改查及完成状态切换
- [x] 同一天重复打卡会被拦截
- [x] 近 7 天和近 30 天图表随数据变化刷新
- [x] 刷新页面后 LocalStorage 数据仍然存在
- [x] Mock API 异常时本地功能保持可用并记录待同步操作

## 响应式验收范围

- 桌面端：大于 960px，计时区双栏、任务打卡区双栏
- 平板端：601–960px，模块自动改为单栏
- 手机端：不超过 600px，输入区、统计卡和页脚重新排列
